A new app is easiest to start from [ng-base-starter](https://github.com/lenneTech/ng-base-starter)
(`lt fullstack init --frontend angular` or `lt frontend angular`), which has everything below in place. This page is for
adding ng-base to an existing app or for understanding what the starter does.

## Installation

```bash
pnpm add @lenne.tech/ng-base better-auth @angular/cdk @spartan-ng/brain @ng-icons/core @ng-icons/lucide tw-animate-css
pnpm add tus-js-client            # optional: uploads (add "url-parse" to allowedCommonJsDependencies in angular.json)
pnpm add modern-screenshot        # optional: screenshots of the bug reporter
pnpm add -D @playwright/test      # optional: /testing
```

Peer dependencies: `@angular/*` `^22.2`, `@angular/cdk` `^22.2`, `@spartan-ng/brain` `>=1.9 <2`, `@ng-icons/core` and
`@ng-icons/lucide` `>=36`, `rxjs` `^7.8`, `better-auth` `>=1.7.16 <1.8.0` (in lock-step with nest-server), optionally
`@better-auth/passkey` (same range), `tus-js-client` `>=4`, `modern-screenshot` `>=4.6` and `@playwright/test`.

## `app.config.ts`

```ts
export const appConfig: ApplicationConfig = {
  providers: [
    provideBrowserGlobalErrorListeners(),
    provideRouter(routes, withComponentInputBinding()),
    provideClientHydration(withEventReplay()),
    provideHttpClient(withInterceptors([ltAuthInterceptor])), // from '@lenne.tech/ng-base/auth/provide'
    provideLtNgBase(),
    provideLtAuth({ systemSetup: { enabled: true } }), // from '@lenne.tech/ng-base/auth/provide'
    provideLtSync(), // opt-in offline sync
    provideLtUi(), // from '@lenne.tech/ng-base/ui/provide': toasts (lazy), color mode
  ],
};
```

- Import providers, guards and the interceptor from the `…/provide` entry points. They carry no Better Auth and no
  component code, so the initial bundle stays small.
- Call `provideLtFiles()` and `provideLtAi()` only when you pass options. Their defaults (`/tus`, `/ai`) apply without
  them, and a call without options only adds the entry point to the initial bundle.
- Render `<hlm-toaster />` in a `@defer (on idle)` block.

## `server.ts`

The app runs on Express with `AngularNodeAppEngine`:

```ts
app.use(ltSecurityHeaders());
app.use(ltSecurityTxt()); // only where somebody reads the contact address
app.use(ltBuildIdentity()); // GET /api/build-identity
app.use(ltApiProxy()); // /api/* → NG_API_URL, only with NG_PUBLIC_API_PROXY=true
app.use(express.static(browserDistFolder, { index: false, maxAge: '1y', redirect: false }));
app.use(ltAngularRequestHandler(new AngularNodeAppEngine(), { appVersion: packageJson.version }));
```

`ltAngularRequestHandler()` reads the `NG_*` environment per request, adds the HTML cache headers and writes the public
part of the configuration into every HTML response. One build therefore runs on every stage, see
[Configuration](./2.configuration.md).

## Styles

`src/styles.css`:

```css
@import 'tailwindcss';
@import '@lenne.tech/ng-base/ui/styles/theme.css';
```

The theme brings the lenne.tech palette, the semantic tokens and the classes of every component. When the CLI's bundle
budget is tight, import the core and only the components the app renders, see [UI](./5.ui.md#styles-and-bundle-size).

## Routes

```ts
export const routes: Routes = [
  {
    path: '',
    canActivateChild: [ltSystemSetupGuard], // sends every visit to /auth/setup while the API has no admin
    children: [
      { path: 'auth/login', canActivate: [ltGuestGuard('/app')], loadComponent: () => import('./auth/login-page').then((m) => m.LoginPage) },
      { path: 'app', canActivate: [ltAuthGuard], loadChildren: () => import('./app.routes.app') },
      { path: 'admin', canActivate: [ltRoleGuard('admin')], loadChildren: () => import('./app.routes.admin') },
    ],
  },
];
```

The guards only decide what the UI shows; the API decides what a user may do. More in
[Authentication](./3.authentication.md).
