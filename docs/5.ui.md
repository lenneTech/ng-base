`@lenne.tech/ng-base/ui` is built on [Spartan UI](https://www.spartan.ng/) and Tailwind CSS 4. It has two layers:

- **Spartan helm** (`Hlm*` directives and components: button, input, dialog, table, tabs, select and many more),
  generated from the Spartan CLI templates.
- **`lt-*` components** on top, for the patterns lenne.tech apps share: form fields, pickers, page layout, notices.

## Styles and bundle size

```css
@import 'tailwindcss';
@import '@lenne.tech/ng-base/ui/styles/theme.css';
```

The theme brings the Spartan preset, the lenne.tech palette (primary, secondary, success, info, warning, error,
neutral, as in nuxt-base-starter), the semantic tokens and the classes of every component, about 172 kB raw and 20 kB
gzip. To stay within the Angular CLI budget, import the core and only the components the app renders. Each file pulls
in the components it builds on:

```css
@import 'tailwindcss';
@import '@lenne.tech/ng-base/ui/styles/core.css';
@import '@lenne.tech/ng-base/ui/styles/components/sonner.css'; /* <hlm-toaster> */
@import '@lenne.tech/ng-base/ui/styles/components/lt-text-field.css'; /* + input, input-group, lt-form-field */
@import '@lenne.tech/ng-base/ui/styles/components/lt-header.css';
```

Measured: core 15 kB, core plus five typical components 62 kB raw and 9 kB gzip.

More for a small initial bundle:

- Import providers from `@lenne.tech/ng-base/ui/provide`, not from `/ui`.
- Render the toaster deferred: `@defer (on idle) { <app-toaster /> }`, a small component that renders `<hlm-toaster />`.
  A toast raised before it has rendered waits for it and appears then.
- Add `provideLtUiOverlayDefaults()` to the providers of the lazy routes that open overlays, not to `app.config.ts`. It
  makes toasts appear above open dialogs.

Use the theme tokens (`bg-primary`, `text-muted-foreground`, `text-error` …) instead of raw colors, so dark mode and the
palette keep working.

## `lt-*` components

| Component                                         | What it is                                                                                                    |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `lt-header`, `lt-navigation-menu`, `lt-footer`    | Page header with logo and actions, horizontal navigation that collapses into the header's mobile menu, footer |
| `lt-page-title`, `lt-page-card`, `lt-breadcrumb`  | Page title with actions, card with footer, breadcrumb trail                                                   |
| `lt-form-field`                                   | Label, control, hint and error of one form field                                                              |
| `lt-text-field`, `lt-password-input`, `lt-select` | Text input with unit or prefix, password input with show/hide toggle, select with optional search             |
| `lt-date-picker`, `lt-date-time-picker`           | Date and date-time pickers, German format by default                                                          |
| `lt-readonly-field`                               | Read-only label and value                                                                                     |
| `lt-data-view`                                    | List of records as table or tiles (`ltDataViewTile`, `ltDataViewCell`)                                        |
| `lt-notice`                                       | Notice box per variant (error, warning, success, info)                                                        |
| `lt-color-mode-button`                            | Light/dark toggle                                                                                             |
| `lt-confirm-dialog`                               | Content of `LtOverlayService.confirm()`                                                                       |
| `[ltToolbar]`, `[ltToolbarItem]`                  | Toolbar with roving tabindex                                                                                  |
| `[ltEnterAction]`                                 | Action on ENTER in an input, for barcode and RFID scanners                                                    |

The form controls work with Signal Forms and two-way binding (`[(value)]`). The documentation of every input is in the
component's source under
[`projects/ng-base/ui/src/lib/lt/`](https://github.com/lenneTech/ng-base/tree/main/projects/ng-base/ui/src/lib/lt).

## Overlays, toasts and color mode

- **`LtOverlayService`**: `open(component, options)` opens a dialog and returns a reference with `close(result)`;
  `confirm(options)` asks a yes/no question and resolves `true` or `false`.
- **Toasts**: `LtToastService` from `@lenne.tech/ng-base`, rendered by Sonner (`provideLtUi()`, `<hlm-toaster />`). An app
  toast library can be bound through `LT_TOAST_ADAPTER`.
- **Color mode**: `LtColorModeService` and `LT_COLOR_MODE_SCRIPT` (set the class before the first paint, so there is no
  flash). Dark mode is the `.dark` class on `<html>`.
- **Transitions**: `LT_TRANSITIONS` with Angular's `animate.enter` / `animate.leave`.

## Other helpers

- `@lenne.tech/ng-base/share`: `LtShareService` shares through the Web Share API and falls back to the clipboard.
- `@lenne.tech/ng-base/utils`: `LtSeoService` (title and meta tags), `LtStorageService` (`localStorage` with prefix),
  `LtScrollService`, `ltFocusFirstInvalid()` for forms, `ltMap()` for mapping API models.
