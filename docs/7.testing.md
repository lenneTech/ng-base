`@lenne.tech/ng-base/testing` holds helpers for Playwright E2E tests. Install `@playwright/test` as a dev dependency.

| Helper                                                                               | Use                                                                                  |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| `waitForHydration()`, `gotoAndWaitForHydration()`                                    | Wait until an SSR page is hydrated before interacting with it                        |
| `fillInput()`, `fillInputs()`                                                        | Type values key by key (clearing the field first), as a user would                   |
| `generateTestUser()`, `createTestUser()`, `loginTestUser()`, `loginTestUserViaApi()` | Create a test user through the API's sign-up and sign in through the page or the API |
| `generateTOTP()`, `extractTOTPSecret()`                                              | One-time codes for 2FA tests                                                         |

Wait for hydration on every SSR page before clicking or typing, so the test acts on the page Angular controls and not
on the server-rendered HTML.

[ng-base-starter](https://github.com/lenneTech/ng-base-starter) uses these helpers in its auth suite against a real
nest-server-starter; its docs describe the backend scenarios.
