# Migration guide: ng-base 18.x → 22.0.0

22.0.0 is a rebuild, not an upgrade. It targets Angular 22, Tailwind CSS 4 and nest-server 12.5 (Better Auth under
`/iam`, REST). None of the 18.x API remains; projects on 18.x keep working on `18.1.3` (tag `v18.1.3`).

## Who should migrate

| Project                                                        | Recommendation                                                                      |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Uses only Storage, Scroll, Forms, SEO helpers (Directus sites) | Migrate the helpers to `@lenne.tech/ng-base/utils` when the app moves to Angular 22 |
| Uses the nest-server integration (GraphQL, legacy JWT)         | Move to the new stack via `ng-base-starter`; the backend must be nest-server ≥ 12.5 |
| New project                                                    | `lt fullstack init --frontend angular`                                              |

## Requirements

- Node `^22.22.3 || ^24.15.0 || >=26`, TypeScript `~6.0`, Angular `^22.2`
- Tailwind CSS 4 instead of Bootstrap
- nest-server ≥ 12.5 for `/auth`, `/files`, `/ai`, `/sync`

## Mapping

| 18.x                                                                      | 22.0.0                                                                                                         |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `BaseModule.forRoot(config)`                                              | `provideLtNgBase()` + feature providers (`provideLtAuth()`, `provideLtFiles()`, `provideLtUi()` …)             |
| `environment.ts` API URLs                                                 | `NG_PUBLIC_API_URL` / `NG_API_URL` at runtime (`ltAngularRequestHandler()`), or `provideLtNgBase({ runtime })` |
| `AuthService` (GraphQL `signIn`, `refreshToken`)                          | `LtAuthService` (`/iam`, cookie session + JWT fallback, signals)                                               |
| `AuthGuard` (class, route data)                                           | `ltAuthGuard`, `ltRoleGuard('admin')`, `ltGuestGuard()` (functions)                                            |
| `GraphQLService`, `GraphQLPlusService`, `GraphQLMetaService`              | removed — use the generated REST client of the project (hey-api)                                               |
| `FileService` / upload components                                         | `injectLtTusUpload()`, `LtFileService`, `<lt-tus-upload>`                                                      |
| `SEOService.initPageForSEO(data)`                                         | `LtSeoService.set(data)` (adds canonical, robots, site-URL resolution)                                         |
| `StorageService.save/load` (prefix + version)                             | `LtStorageService.save/load` (prefix from `NG_PUBLIC_STORAGE_PREFIX`), `storage.signal(key, fallback)`         |
| `ScrollService.scrollTo(id)`                                              | `LtScrollService.scrollTo(id, { offset })`                                                                     |
| `FormsService.validateAllFormFields`, `scrollToInvalidControl`            | Signal Forms `submit()` marks fields touched; `ltFocusFirstInvalid()`                                          |
| `Standard` / `Helper.map`                                                 | `LtStandard` / `ltMap()` (dates are only converted with `dateStringToDate`)                                    |
| `Helper.urlString`, `getUID`, `delay`, `deepFreeze`, `isEqual`, `getDiff` | `ltSlug`, `ltUid`, `ltDelay`, `ltDeepFreeze`, `ltIsEqual`, `ltGetDiff`                                         |
| Bootstrap components (`base-components`)                                  | Spartan helm (`Hlm*`) and `lt-*` components in `@lenne.tech/ng-base/ui`                                        |
| CMS / prototype modules                                                   | removed                                                                                                        |

## Steps

1. Remove the 18.x stack first; its peer dependency `@angular/core: 18.*` makes `ng update` refuse to run:
   `pnpm remove @lenne.tech/ng-base apollo-angular @apollo/client graphql graphql-ws bootstrap js-sha256`.
2. Update Angular one major at a time, so every version's migrations run (`ng update` refuses to skip majors):
   `ng update @angular/core@19 @angular/cli@19`, then `@20`, `@21` and `@22` (https://angular.dev/update-guide). Then
   switch to Tailwind CSS 4 (`ng add tailwindcss`).
3. Add the new dependency:
   `pnpm add @lenne.tech/ng-base@22 better-auth @angular/cdk @spartan-ng/brain @ng-icons/core @ng-icons/lucide tw-animate-css`.
4. Add the providers to `app.config.ts` and the theme import to `styles.css` (see the package README).
5. Replace the imports along the mapping table; remove `BaseModule` and the GraphQL setup.
6. Run `pnpm run check` and the E2E tests.
